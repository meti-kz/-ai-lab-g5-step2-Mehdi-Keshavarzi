## ۱. معرفی پروژه

این مخزن شامل پیاده‌سازی بخش کدنویسی (مرحله دوم) از پروژه آزمایشگاه هوش مصنوعی گروه پنجم است.

هدف اصلی این مرحله، توسعه اسکریپت‌های پایتون برای تولید نقشه‌های مصنوعی، دریافت نقشه‌های واقعی از OpenStreetMap، تبدیل ساختار گراف‌های مختلف به یک قالب مشترک و ذخیره نقشه‌های تولیدشده برای استفاده در مراحل بعدی پروژه است.

پیاده‌سازی این بخش بر اساس مشخصات اولیه و ساختار داده‌ای تعیین‌شده در مرحله طراحی پروژه انجام می‌شود.

تمرکز اصلی فعالیت من در این مخزن بر تولید گراف، دریافت نقشه واقعی، یکسان‌سازی ساختار گراف‌ها، اعتبارسنجی و مدیریت فایل‌های GraphML است.

## ۲. مسئولیت‌های من در پروژه

به‌عنوان عضو دوم تیم و مسئول بخش کدنویسی، وظایف من شامل موارد زیر است:

- ایجاد محیط برنامه‌نویسی پایتون و نصب کتابخانه‌های موردنیاز.
- نوشتن اسکریپت‌های تولید نقشه مصنوعی.
- ایجاد گره‌ها (Nodes) و یال‌ها (Edges) برای شبکه‌های جاده‌ای مصنوعی.
- دریافت اطلاعات شبکه جاده‌ای واقعی از OpenStreetMap با استفاده از کتابخانه OSMnx.
- تبدیل نقشه‌های مصنوعی و واقعی به یک ساختار گراف مشترک.
- آماده‌سازی داده‌های گراف برای استفاده در الگوریتم‌های مسیریابی.
- اعتبارسنجی ساختار گراف‌ها و بررسی ویژگی‌های ضروری آن‌ها.
- ذخیره‌سازی و بارگذاری اطلاعات گراف در قالب GraphML.
- آزمایش کدها برای اطمینان از عملکرد صحیح اسکریپت‌های تولید و بارگذاری نقشه.

## ۴. فناوری‌ها و کتابخانه‌های مورد استفاده

برای پیاده‌سازی این مرحله از زبان برنامه‌نویسی Python و کتابخانه‌های زیر استفاده می‌شود:

| فناوری یا کتابخانه | کاربرد |
|---|---|
| Python 3.10 یا بالاتر | زبان اصلی برنامه‌نویسی |
| NetworkX | ساخت و مدیریت گراف‌ها |
| OSMnx | دریافت و پردازش شبکه جاده‌ای واقعی |
| GraphML | ذخیره‌سازی و تبادل اطلاعات گراف |

تمام وابستگی‌های موردنیاز پروژه در فایل `requirements.txt` قرار داده شده‌اند.

## ۵. ماژول‌های پیاده‌سازی‌شده

### ۵.۱. تولید نقشه مصنوعی

**مسیر فایل:** `src/synthetic_map.py`

این ماژول برای تولید یک شبکه جاده‌ای مصنوعی شهری با استفاده از ساختار شبکه‌ای منظم (Grid) طراحی شده است.

وظایف اصلی این ماژول عبارت‌اند از:

- ایجاد گره‌ها با شناسه‌های منحصربه‌فرد.
- ایجاد اتصالات افقی و عمودی بین گره‌ها.
- تولید یال‌های جهت‌دار در هر دو مسیر رفت و برگشت.
- اختصاص مقدار فاصله به اتصالات جاده‌ای.
- ایجاد مختصات جغرافیایی برای گره‌ها.
- ذخیره گراف تولیدشده در قالب GraphML.

شبکه مصنوعی برای آزمایش و انجام فعالیت‌های بعدی پروژه استفاده می‌شود و لزوماً نشان‌دهنده ساختار واقعی خیابان‌های شهر شیراز نیست.

مسیر پیش‌فرض خروجی:

```text
data/synthetic/shiraz_synthetic.graphml
```

### ۵.۲. دریافت نقشه واقعی

**مسیر فایل:** `src/real_map_loader.py`

این ماژول مسئول دریافت اطلاعات واقعی شبکه جاده‌ای از OpenStreetMap با استفاده از کتابخانه OSMnx است.

وظایف اصلی این ماژول عبارت‌اند از:

- برقراری ارتباط با OpenStreetMap از طریق OSMnx.
- دریافت شبکه جاده‌ای محدوده مطالعاتی انتخاب‌شده.
- پشتیبانی از انواع مختلف شبکه‌های حمل‌ونقل.
- استخراج اطلاعات گره‌ها، یال‌ها و ویژگی‌های آن‌ها.
- حفظ اطلاعات مهم مربوط به مسیرها و جاده‌ها.
- آماده‌سازی شبکه دریافت‌شده در ساختار گراف استاندارد پروژه.
- ذخیره گراف نهایی در قالب GraphML.

محدوده مطالعاتی پیش‌فرض، شهر شیراز در استان فارس ایران است.

نوع شبکه پیش‌فرض `drive` در نظر گرفته شده است که شبکه قابل استفاده برای خودروها را نشان می‌دهد. این مقدار بر اساس نیاز نهایی پروژه قابل تغییر است.

مسیر پیش‌فرض خروجی:

```text
data/real/shiraz_drive.graphml
```

### ۵.۳. ساخت و یکسان‌سازی گراف‌ها

**مسیر فایل:** `src/graph_builder.py`

این ماژول برای ایجاد یک ساختار مشترک بین نقشه‌های مصنوعی و واقعی طراحی شده است.

وظایف اصلی این ماژول عبارت‌اند از:

- تبدیل ساختارهای مختلف گراف به `NetworkX MultiDiGraph`.
- حفظ جهت‌دار بودن اتصالات و امکان وجود چند یال بین دو گره.
- یکسان‌سازی مختصات جغرافیایی.
- بررسی وجود ویژگی‌های ضروری در گره‌ها و یال‌ها.
- اعتبارسنجی فاصله جاده‌ها و ویژگی‌های گراف.
- یکسان‌سازی وزن یال‌ها.
- ذخیره و بارگذاری گراف‌ها در قالب GraphML.

هدف این ماژول آن است که نقشه‌های حاصل از منابع مختلف بتوانند در مراحل بعدی پروژه با الگوریتم‌های مسیریابی یکسان استفاده شوند.

## ۶. ساختار مشترک گراف‌ها

برای حفظ سازگاری میان منابع مختلف داده، در این پروژه از ساختار گراف زیر استفاده می‌شود:

**نوع گراف:**

`networkx.MultiDiGraph`

این ساختار یک گراف جهت‌دار است که امکان وجود چند یال بین دو گره را فراهم می‌کند.

### ویژگی‌های گره‌ها (Node Attributes)

| ویژگی | توضیحات |
|---|---|
| `osmid` | شناسه گره |
| `x` | طول جغرافیایی (Longitude) |
| `y` | عرض جغرافیایی (Latitude) |

### ویژگی‌های یال‌ها (Edge Attributes)

| ویژگی | توضیحات |
|---|---|
| `length` | طول مسیر بر حسب متر |
| `weight` | وزن مورد استفاده در مسیریابی |
| `highway` | نوع یا طبقه‌بندی جاده |
| `name` | نام خیابان یا جاده، در صورت وجود |
| `oneway` | مشخص‌کننده یک‌طرفه بودن مسیر |

وزن اصلی مورد استفاده در این مرحله، `length` است که فاصله مسیر را بر حسب متر نشان می‌دهد.

استفاده از این ساختار مشترک باعث می‌شود نقشه‌های مصنوعی و واقعی در مراحل بعدی پروژه به شکل یکسان مورد استفاده قرار گیرند.

## ۷. نصب و راه‌اندازی محیط برنامه‌نویسی

برای اجرای پروژه استفاده از Python نسخه 3.10 یا بالاتر پیشنهاد می‌شود.

ابتدا باید یک محیط مجازی پایتون ایجاد شود:

```bash
python -m venv .venv
```

سپس محیط مجازی را فعال کنید.

**در ویندوز:**

```bash
.venv\Scripts\activate
```

**در لینوکس و macOS:**

```bash
source .venv/bin/activate
```

در مرحله بعد، کتابخانه‌های موردنیاز را نصب کنید:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## ۸. نحوه اجرای کدها

تمام دستورات زیر باید از مسیر اصلی پروژه اجرا شوند.

### تولید نقشه مصنوعی

```bash
python -m src.synthetic_map
```

برای تغییر ابعاد شبکه مصنوعی می‌توان از دستور زیر استفاده کرد:

```bash
python -m src.synthetic_map --rows 8 --cols 8 --spacing 120
```

### دریافت نقشه واقعی

```bash
python -m src.real_map_loader
```

برای مشخص کردن محدوده مطالعاتی و نوع شبکه:

```bash
python -m src.real_map_loader --place "Shiraz, Fars Province, Iran" --network-type drive
```

برای دریافت شبکه مخصوص عابران پیاده:

```bash
python -m src.real_map_loader --network-type walk --output data/real/shiraz_walk.graphml
```

نوع شبکه باید بر اساس نیاز نهایی پروژه و تصمیم گروه انتخاب شود.

### اعتبارسنجی فایل GraphML

پس از تولید یا دریافت نقشه، می‌توان ساختار آن را با دستور زیر بررسی کرد:

```bash
python -m src.graph_builder data/synthetic/shiraz_synthetic.graphml
```

گزارش اعتبارسنجی شامل موارد زیر است:

- نوع گراف
- تعداد گره‌ها
- تعداد یال‌ها
- ویژگی‌های ناقص یا نامعتبر
- وضعیت اعتبارسنجی گراف

## ۹. خروجی‌های مورد انتظار

این پیاده‌سازی برای تولید فایل‌های زیر طراحی شده است:

| نام فایل | توضیحات |
|---|---|
| `shiraz_synthetic.graphml` | شبکه جاده‌ای مصنوعی |

این فایل‌ها ورودی‌های گراف موردنیاز برای اجرای الگوریتم‌های مسیریابی و ارزیابی در مراحل بعدی پروژه را فراهم می‌کنند.

## ۱۰. آزمایش و اعتبارسنجی

در پیاده‌سازی بخش کدنویسی، موارد زیر مورد بررسی قرار می‌گیرند:

- اجرای صحیح فرآیند تولید گراف مصنوعی.
- صحت ایجاد گره‌ها و یال‌های جهت‌دار.
- سازگاری مختصات جغرافیایی.
- معتبر بودن فاصله مسیرها و وزن یال‌ها.
- تبدیل موفق گراف‌ها به ساختار مشترک MultiDiGraph.
- ذخیره‌سازی و بارگذاری فایل‌های GraphML.
- شناسایی ویژگی‌های ناقص یا نامعتبر گراف.

دریافت نقشه واقعی از OpenStreetMap به اتصال اینترنت و دسترسی به سرویس‌های مربوطه نیاز دارد.

برای اطمینان از دریافت صحیح نقشه محدوده انتخاب‌شده، اجرای کد دریافت نقشه واقعی در محیط محلی پایتون ضروری است.
